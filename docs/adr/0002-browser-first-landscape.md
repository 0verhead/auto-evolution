# Browser first, in landscape

The game ships first as a browser game in landscape that is playable on phones and desktop, and is packaged for app stores and Steam later. We chose the browser over a native mobile engine so the core hook (Age Specialties keeping old Units relevant) can be tested and iterated on quickly without tying the project to an engine. We chose landscape because the Line is horizontal with two Lines facing each other in battle, as in Super Auto Pets, so portrait would mean tiny cards or a vertical Line.
